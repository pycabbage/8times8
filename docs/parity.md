# 8times8 — 原版との照合記録

[技術選定](design/technology-selection.md)は設計時点の初期範囲を示す。
本記録はその後の移植で確認した結果と、配布前に残る確認事項をまとめたもの。
原版の `vendor/` は比較・計測にのみ使用する。ただし `vendor/build/icon.png` はアプリアイコンに使用し、
それ以外の原版のコード・画像・音素材は流用・同梱しない。

## 検証結果

以下は v0.3.0 に対する確認結果で、現行版の再検証結果ではない。

- 独立した盤面の参照結果（oracle）と 6 ケースで一致：初期状態、64 枚の反転、価格と巡回、
  1B の余剰処理、アイテム、1D 群。
- ゲームコア単体のテスト 46 件が通過。規模を制限したテストデータでは、1D・1F・1H の
  各レベルで 32 群、計 2,048 候補を確認した。
- 1280×820 で Linux（Vulkan／Xvfb）と Windows GNU 版 `.exe`（Wine）を確認した。
  確認項目は HUD、ショップ、テーマ切替、押下だけでは反転しないこと、長押し・ドラッグ、
  ホイール、保存後の再起動と復元。
- 同条件で原版と比較し、初期背景とタイルの RGB が一致し、タイル端の位置差は 1 px 以内だった。
  タイル面の幅が 4 px 未満になると、開放候補の内枠が外周だけの表示に切り替わった。
  初期の単一区画では最小まで縮小しても境界に達しないため、「アイテム直前」のテストデータを使った。

## 差分と未確認事項

- v0.3.1（公開前）：GPU／Windows CPU とも、物理 1 px の被覆率で輪郭をアンチエイリアスする。セル幅が物理 1 px 以下では白黒の面積比で区画を一色にまとめ、1～2 px で段階的にセル表示へ戻してモアレを抑える。
  既存の 4／10／12 px の LOD は維持する。GPU と CPU ではブレンド空間が異なるため、縁の色は厳密には一致しない。
- フォントのアンチエイリアス、半透明やグラデーションの描画、アイテムの飛翔演出は完全には一致しない。
- v0.3.0 の音声は合成音のテスト 6 件で確認した。実スピーカーでの原版との比較は未実施。
- デバッグ HUD、原版 v1／v2 の JSON の貼り付け、現行セーブのクリップボード経由のコピー・貼り付けは
  `debug_assertions` が有効なビルドでのみ使える。旧ストレージは自動で検索せず、置き換えない。
  リリース版のディスクへの自動保存と再起動時の復元は従来どおり。
- HUD の文字はシステムフォントを使い、ウィンドウの DPI に応じた物理ピクセルサイズでラスタライズする。
  日本語グリフを含むフォントが必要（Linux では例として Noto Sans CJK JP）。
- マウスホイールは 1 ノッチで ×1.20（縮小は ÷1.20）。トラックパッドの倍率は従来どおり。
- Windows GNU 版は GUI サブシステムを使用し、winit がモニターごとの DPI 対応を要求する。
  ウィンドウとタスクバーのアイコンは実行時に設定し、エクスプローラー上の実行ファイルのアイコンは変更しない。
- Wine での起動・操作確認は Windows 実機での検証ではない。Windows 実機は未確認。

## 配布前のチェック

- Ubuntu runner（`ubuntu-24.04`）で ALSA 開発パッケージ（`libasound2-dev`）と Windows GNU 向け
  MinGW-w64 を用意し、ロック済みの依存で両ターゲットをビルドする。Linux では実行時の ALSA と Vulkan の依存も確認する。
- Linux x86-64 GNU 用の `tar.gz` と Windows x86-64 GNU 用の ZIP を展開し、`8times8` の起動、
  描画・入力・音声、保存と再起動を対象環境で確認する。Windows は Wine だけでなく実機で確認する。
  Linux でアプリメニューに登録する場合は、アーカイブの `share/` の内容を `~/.local/share/` などに配置し、
  `8times8` を `PATH` 上に置く。
- アーカイブに必要なライセンス通知があり、上記アイコン以外の原版素材が含まれないこと、
  SHA-256 チェックサムが一致することを確認してから公開する。
